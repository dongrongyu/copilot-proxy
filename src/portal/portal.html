Reasoning Effort

Set the thinking effort applied to every request whose model supports it. Applies instantly to all connected clients — no restart, no per-client config.

The proxy sends this value, clamped to the nearest effort the model actually supports (preferring the next stronger level). Stored in config.yaml.
high Applies instantly — also settable via copilot-proxy effort <value>.

How each model resolves

Only models advertising a reasoning_effort capability are affected. Others (e.g. 4.5, haiku) ignore effort entirely and are sent unchanged.
